## list all user info 

````
cat  /etc/passwd
````

## list top 10 lines

````
head  /etc/passwd
````

## list last 10 lines

````
tail /etc/passwd
````

## list user pass info
````
cat /etc/shadow
````


## addnew user
````
adduser natasha
````

## switch to user
````
su - natasha
````

## logout from user
````
exit
````

## delete user
````
userdel -r natasha
````
